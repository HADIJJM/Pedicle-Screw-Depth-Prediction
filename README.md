# Pedicle Screw Depth Prediction

Research prototype for CT-based vertebral segmentation, anatomical analysis, depth estimation, boundary checks and visualization.

## Modules
1. 3D Segmentation (T10–L5)
2. Anatomical and HU analysis
3. Depth estimation
4. Anatomical constraints
5. Visualization

Files are placeholders, not implemented functionality. Do not use for clinical decisions.

Raw medical images, checkpoints, and generated outputs must not be committed to Git.
